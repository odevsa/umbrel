### Umbrel OS

Applications packaged for Umbrel OS and available via **Community App Stores**:

- **MarkNote** (`odevsa-marknote`)
- **Monolai** (`odevsa-monolai`)

#### Installation

1. Open your **Umbrel Dashboard** and navigate to the **App Store**.
2. Click the **menu icon (three dots ...)** in the top right corner and select **Community App Stores**.
3. Paste the repository URL:
   ```
   https://github.com/odevsa/umbrel
   ```
4. Search for **MarkNote** or **Monolai** in the App Store and click **Install**.
